# Lloyds Banking Group Data Science Job Simulation (Forage)

This repository contains my work completed during the Lloyds Banking Group Data Science Virtual Experience Program on Forage.

## Project Overview
The simulation focused on applying data science and analytical techniques to solve business problems in the banking domain. The tasks involved data preprocessing, exploratory data analysis, visualization, and predictive modeling using Python.

## Tasks Completed
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Data visualization
- Feature engineering
- Predictive modeling using Machine Learning
- Business insight generation
- Presentation of findings

## Tools & Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Key Skills Demonstrated
- Data Analysis
- Machine Learning
- Problem Solving
- Business Understanding
- Data Visualization
- Analytical Thinking
